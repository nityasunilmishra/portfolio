# Nitya Mishra — Developer, Spiritualist & Lifelong Learner

An ultra-modern, responsive personal portfolio for **Nitya Mishra** — 2nd Year IT Engineering undergraduate at **DJSCE**, Mumbai (9.9 CGPA). Showcasing high-impact engineering work, AI systems, browser extensions, a live coding tracker with daily-updating LeetCode and Codolio charts, and a "Beyond Code" section exploring life as a spiritualist and reader.

---

## Highlights

- **Whisper Flow-inspired Design**: Clean teal/emerald color system with glassmorphism, dark and light themes, ambient glows, and constellation particle canvas.
- **Live Coding Tracker**: Daily-updating LeetCode and Codolio stats with custom-drawn canvas charts showing 30-day problem-solving history. Data is cached locally and refreshed every 24 hours.
- **Flagship Projects**: Lumina AI clinical dashboard, ELI5 Chrome extension with Gemini, and DSA repository.
- **Beyond Code Section**: Personal side — spiritualist, avid reader, and lifelong seeker.
- **Scroll Reveal Animations**: Sections fade in as you scroll, with micro-interactions throughout.
- **Responsive**: Optimized for mobile (320px+), tablets, laptops, and ultra-wide displays.
- **Contact**: 1-click email copy, interactive contact form, direct links to LinkedIn, GitHub, LeetCode, and Codolio.
